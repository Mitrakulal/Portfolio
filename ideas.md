## Chosen Direction: Electric Editorial

### Design Movement
Contemporary Swiss editorial design crossed with post-internet art direction and kinetic typography. The page should feel like a printed magazine cover that learned to move.

### Core Principles
1. **Make the hierarchy impossible to miss.** Headlines should carry the composition, not decorate it.
2. **Use tension instead of polish-by-default.** Pair hard edges, irregular rhythm, and deliberate visual interruptions with a small set of repeatable rules.
3. **Treat work as evidence.** Projects should feel like artifacts with context, not a row of identical cards.
4. **Keep the interaction alive but quick.** Hover, focus, and scroll states should reveal character without slowing the experience.

### Color Philosophy
The base is near-black ink, chosen to make the portfolio feel tactile and editorial. Acid chartreuse becomes the ownable signature color: it acts as a highlighter stroke across the page, creating urgency and recognition. Bone-white type keeps the dark field legible, while a restrained cobalt accent appears only where a project needs a second signal.

### Layout Paradigm
A vertical editorial strip with a persistent rail, asymmetrical project placements, and full-bleed interruptions. The composition should resist a centered landing-page stack: the eye moves between the left rail, oversized headline, offset metadata, and project artifacts.

### Signature Elements
- A left-side vertical rail with the mark, section index, and live status.
- Acid chartreuse highlight bars used as punctuation behind select words.
- Project labels treated like stamped issue covers, with oversized serial numbers and angled metadata.

### Interaction Philosophy
Every interaction should feel like handling a printed object: hover exposes a caption, buttons press with a small physical recoil, and project items shift just enough to show depth. Motion is short, intentional, and never decorative for its own sake.

### Animation
Entrance reveals use clipped text and staggered opacity with 40–70ms offsets. Project hover states use a fast 180ms transform/opacity transition with custom ease-out. Avoid looping motion except for a tiny live-status indicator. Respect `prefers-reduced-motion` by removing reveal transforms and leaving color/focus changes intact.

### Typography System
Use **Space Grotesk** for display and navigation, with **DM Mono** for metadata, labels, and serial numbers. Headlines are set in heavy weight with tight tracking and occasional italic emphasis. Body copy stays compact at 16–18px with generous line-height. Never use Inter.

### Brand Essence
A portfolio for a multidisciplinary creative who turns friction into memorable visual systems — different because the presentation itself behaves like a piece of the work. Personality: **audacious, exacting, kinetic**.

### Brand Voice
Headlines are direct, vivid, and slightly confrontational. CTAs are invitations into the work, never generic conversion language.

Example lines: “I make the kind of work that interrupts the scroll.” / “Open the case file.”

### Wordmark & Logo
Use a compact symbol built from two opposing brackets that imply an electric spark between them. The symbol sits in a small square stamp on the rail; the name appears separately as typeset text, never as the logo itself.

### Signature Brand Color
**Acid Chartreuse — #D7FF3F**.
